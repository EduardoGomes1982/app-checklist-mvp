# Prisma Check - MVP de Validação 🚗✅

Um Progressive Web App (PWA) de fachada desenvolvido para validar a ideia de um sistema de checklist de entrada e saída de veículos para o Prisma Auto Center e outras oficinas mecânicas.

## 🎯 Objetivo

Este projeto não utiliza um banco de dados real. Seu propósito é servir como um **Protótipo Funcional (MVP)** para que mecânicos e clientes possam testar a fluidez e a usabilidade de um aplicativo de checklist pelo celular. Ao final do fluxo simulado, o usuário é direcionado para um formulário de pesquisa para avaliar a experiência.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica.
- **Tailwind CSS (via CDN):** Estilização ágil e responsiva focada em dispositivos móveis (Mobile First).
- **JavaScript (Vanilla):** Controle de transição de telas e uso do `localStorage` para simular a persistência de dados.

## 📂 Estrutura do Projeto

```text
├── index.html     # Estrutura da interface e formulários
├── style.css      # Regras de animação e transição de abas
├── script.js      # Lógica de navegação e simulação de salvamento
```
